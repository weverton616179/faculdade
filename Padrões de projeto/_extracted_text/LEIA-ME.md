## Observações

- Os três arquivos `Padrões de Projetos - Herança, Polimorfismo e Method*.pptx`
  são **cópias idênticas** (mesmo hash MD5: `926616348422BDA801D85CC194950DCD`),
  por isso há um único arquivo de texto para eles.
- Os diagramas e capturas de tela dos slides **não** aparecem aqui (só o texto);
  para ver as figuras, abra o `.pptx` original.
- Os textos foram extraídos preservando a ordem dos slides, com marcadores
  `=== slideN ===`.
- Para regerar a extração, descompacte o `.docx`/`.pptx` (é um ZIP) e converta
  `word/document.xml` e `ppt/slides/slideN.xml` para texto.
